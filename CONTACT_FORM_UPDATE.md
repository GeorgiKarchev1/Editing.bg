# Обновяване на контакт формата - Editing.bg

## Преглед на промените

Успешно заменихме EmailJS с собствена API система, която работи с вашия Plesk сървър. Новата система е безплатна, по-сигурна и по-надеждна.

## 🆕 Нови файлове

### API Endpoints
- `src/app/api/send-email/route.ts` - Основен API endpoint за изпращане на имейли
- `src/app/api/send-email/validate.ts` - Валидация и сигурност
- `src/app/api/send-email/validate.test.ts` - Тестове за валидацията

### Компоненти
- `src/components/ContactForm.tsx` - Новият контакт формуляр компонент

### Конфигурация
- `server.js` - Plesk сървър файл
- `test-email.js` - Тестов скрипт за SMTP
- `PLESK_SETUP.md` - Инструкции за Plesk конфигурация
- `DEPLOY_PLESK.md` - Пълни инструкции за деплой

## 🔧 Промени в съществуващи файлове

### package.json
- Премахнат `@emailjs/browser`
- Добавен `dotenv` за environment variables
- Добавен `test:email` скрипт

### next.config.js
- Променен `output` от `'export'` на `'standalone'` за Plesk

### src/app/page.tsx
- Заменен EmailJS код с новия ContactForm компонент
- Подобрена обработка на грешки

## 📧 SMTP конфигурация

### Environment Variables
```env
SMTP_HOST=localhost
SMTP_PORT=587
SMTP_USER=noreply@editing.bg
SMTP_PASS=your_smtp_password
NODE_ENV=production
NEXT_PUBLIC_SITE_URL=https://editing.bg
```

### Plesk настройки
1. Създайте имейл акаунт: `noreply@editing.bg`
2. Активирайте SMTP достъп
3. Добавете environment variables в Plesk

## 🔒 Сигурност

### Rate Limiting
- 5 запитвания на IP адрес на 15 минути
- Автоматично блокиране при превишаване

### Валидация
- Име: 2-100 символа
- Имейл: валиден формат
- Съобщение: 10-2000 символа
- Тип проект: от предварително дефиниран списък

### Sanitization
- Премахване на HTML тагове
- Блокиране на javascript протокол
- Trim на whitespace
